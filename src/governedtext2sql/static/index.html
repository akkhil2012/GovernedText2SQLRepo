UNDER THE HOOD

Three paths. One governed dataset.

TRANSPARENCY BY DESIGN
01

Direct LLM SQL

Question → schema prompt → generated SQL → SQL policy validation → PostgreSQL.

A query can execute successfully while counting the wrong thing.
02

Semantic retrieval

Question → retrieved catalog definitions → typed metric plan → reviewed SQL → PostgreSQL.

Local lexical retrieval supplies business context; no vector database is required.
03

Virtual knowledge graph

Question → typed metric plan → SPARQL → Ontop OWL rewriting + R2RML unfolding → PostgreSQL.
